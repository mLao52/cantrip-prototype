# Features and Functions
## General
- Responsive layout
- Singe page application
- Data saved on local storage
- Erase data button
- Values inappropriate for their fields are unable to written.
## Homepage
- Dice roller with custom sfx based on roll value but only on singular d20s.
- Character view
- Character hit points
- Pinned notes view w/ add notes button
## Character Sheet
- 5e style character sheet
- Add or overwrite value
- Appropriate stat scaling based on 5e ruleset
- Textarea for writing down appropriate details
## Notes
- Clicking will expand card
- Pin button
- Delete button
## Compendium
- dnd5e api to search items within the src without exiting the application
